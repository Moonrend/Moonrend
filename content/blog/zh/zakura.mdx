## Zakura

协同提升 Agent 的智能。

许多 AI 平台都提供了连接器功能，ChatGPT 提供了「插件」，Claude 提供了连接器和自定义 MCP，越来越多的平台愿意将自己的数据开放出来。随着规范的发展，越来越丰富的 MCP 功能，越来越多的 skill、Agent 项目，可有一个问题没有解决：我们的数据依旧是孤立的。

Codex 无法知道你与 Claude Code 说了什么，云端的 Agent 无法知道你本地做过什么，本地 Agent 需要反复配置云端搜索功能，所有的 Agent 的记忆都无法共享，skill 相互孤立而仅靠不可靠的内置同步流转，且难以稳定地更新——我们陷入了新的孤岛。

如果说，我们已经将 Agent 安装到了每一台电脑、每一个最终用户面前，那么，我们还有什么可以做的？

我无法回答这个问题，但或许，我们可以更好地将其连接起来，一次，而不是几十次。我不想一次次配置我的 Notion MCP，不想一次次思考怎么导出记忆，不想一次次在不同 Agent 之间复制配置、连接技能和数据。我构建了一个平台来解决这一切。

Zakura 是我构建的平台，它将 MCP、skill、云端 Agent、自托管的服务、模型路由、持久文件系统与运行环境聚合起来，并以统一的方式提供给最终的 AI 工具：

1. **使用云端 Agent**：Zakura 内置了运行在云端的 agent，支持实时地在多个设备上同步进度，统一访问工具技能，并在它自己的云端沙盒中运行，永远在线，随时可用。
2. **作为代理网关提供**：最简单的使用方法，无需任何额外设置，将您的上游模型配置在 Zakura 中，然后使用我们提供的 OpenAI 和 Anthropic 兼容端点将其接入在你的 Agent 中，合并云端与本地的功能，并且将你与 agent 的对话转至云端存储，以便它随时查询、分析和继续。
3. **作为 MCP 提供**：我们将以上所有功能作为 MCP 提供，支持最新的 MCP 协议，所以你可以将所有 tools 与 skill 聚合在 Zakura 中，我们将一次性提供给任何支持的 agent。

此外，Zakura 还支持一键部署 SearXNG、Firecrawl、Jina Reader 或者其他自托管服务，我们正在积极扩展其支持的范围。

我不确定这个思想是否指向正确的未来，但或许你可以来试一试。我们提供了云端 SaaS，包括免费的云端环境（我只是一名高中生，项目没有任何资金，所以请手下留情谢谢。）以便大家使用，完全免费。
